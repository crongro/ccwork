# 태그 기능 정의서 (확정본)

## 기능 개요

노트에 태그를 추가하고 관리할 수 있다. 태그는 노트의 분류/검색을 위한 메타정보로 사용된다.

## 데이터 구조

`Note` 타입에 `tags: string[]` 필드를 추가한다.

```ts
interface Note {
  id: string;
  title: string;
  content: string;
  tags: string[]; // 신규 추가
  createdAt: string;
  updatedAt: string;
}
```

- 태그는 문자열 배열로 노트 내부에 직접 저장한다 (정규화하지 않음).
- 빈 배열(`[]`)을 기본값으로 한다. 기존 노트도 마이그레이션 시 빈 배열로 채운다.

## 기능 요구사항

### 1. 태그 추가

- `NoteEditor`의 제목 입력란 바로 아래에 **Chip Input** 컴포넌트를 배치한다.
- 텍스트 input에 태그를 입력하고 **Enter** 또는 **쉼표(`,`)** 키로 확정하면 칩으로 변환된다.
- 확정된 칩은 input 좌측에 나란히 표시된다.
- input이 비어 있는 상태에서 **Backspace**를 누르면 마지막 칩이 삭제된다.

### 2. 태그 삭제

- 각 칩은 **hover 시에만** × 버튼이 노출된다 (기본 상태에서는 숨김).
- × 버튼 클릭 시 해당 태그가 즉시 제거된다.

### 3. 태그 표시

- **노트 상세/편집 화면(`NoteEditor`)**: 제목 아래, 본문 위 영역에 태그 칩 목록을 표시한다.
- **노트 목록(`NoteItem`)**: 이번 스코프에서는 표시하지 않는다.

## 검증 규칙 (엣지케이스)

- **중복 금지**: 이미 존재하는 태그를 추가하려 하면 무시한다 (에러 메시지 없이 input만 비움). 대소문자는 구분하지 않고 비교한다 (`React` == `react`).
- **공백 처리**: 입력값은 `trim()` 후 저장한다. trim 결과가 빈 문자열이면 추가하지 않는다.
- **저장 형태**: 원본 입력 그대로 저장하되 비교만 소문자로 한다. (예: 사용자가 `React`로 먼저 입력하면 `React`로 저장)
- **최대 길이**: 태그 1개당 최대 **15자**. 초과 입력은 input에서 차단한다.
- **최대 개수**: 노트 1개당 최대 **10개**. 초과 시 추가 입력을 차단한다.
- **빈 노트**: 태그가 0개인 노트도 정상 저장/표시된다 (태그 영역은 placeholder만 표시).

## 저장/동기화

- 태그 변경은 노트 본문 저장과 함께 일괄 처리된다 (별도의 태그 저장 API 없음).
- 기존 `updateNote` API에 `tags` 필드를 포함시켜 PUT/PATCH 한다.
- 타임스탬프 갱신 규칙은 기존과 동일하게 `src/api/notes.ts`에서 `updatedAt`을 세팅한다.

## UI 상세

- **칩 스타일**: 둥근 모서리(pill), 옅은 배경, 본문보다 작은 폰트.
- **× 버튼**: 칩 hover 시 우측에 등장. 칩 자체가 hover 트리거.
- **input placeholder**: `태그 입력 후 Enter` (태그가 0개일 때만 표시).
- **키보드 동작 요약**:
  - `Enter` / `,` → 현재 입력값 확정
  - `Backspace` (input 비어있음) → 마지막 칩 삭제

## 비고

- 태그 검색/필터링 기능은 이번 스코프에 포함하지 않는다.
- 전역 태그 목록 관리(태그 자동완성, 이름 일괄 변경 등)는 향후 확장 시 고려한다.
- 정규화 구조(별도 `tags` 컬렉션)로의 전환은 필요 시 마이그레이션으로 처리한다.
