# Tag Filter spec-fixed

## 확정된 요구사항

### 기능 설명

사이드바 좌측 상단에 현재 노트들에서 사용 중인 태그 목록을 노출한다.
태그를 클릭하면 해당 태그가 달린 노트만 목록에 표시되고, 카드와 카드 내 태그 뱃지가 하이라이트된다.

### 결정 사항

| 항목            | 결정                                                              |
| --------------- | ----------------------------------------------------------------- |
| 태그 선택 방식  | 단일 선택. 재클릭 시 해제                                         |
| 태그 목록 구성  | 현재 노트들에 실제로 달린 태그만 집계                             |
| 하이라이트 방식 | 카드 전체 강조 + 카드 내 태그 뱃지 강조 (둘 다)                   |
| 필터링 동작     | 해당 태그 없는 노트는 숨김                                        |
| 태그 없는 노트  | 필터 활성화 시 항상 숨김                                          |
| 태그 해제       | 선택된 태그 재클릭으로 해제                                       |
| 태그 없을 때    | "태그 없음" 텍스트 표시                                           |
| 향후 확장       | selectedTag: string \| null 단일 상태로 구현, 배열 확장 여지 확보 |

### 최소 동작 시나리오

1. **태그 선택 → 필터링**: 사이드바 태그 클릭 → 해당 태그 달린 노트만 표시, 카드+뱃지 하이라이트
2. **태그 해제 → 전체 복원**: 선택된 태그 재클릭 → 전체 노트 다시 표시
3. **태그 없는 상태**: 모든 노트에 태그가 없으면 사이드바에 "태그 없음" 표시

### 경계 조건

- 태그가 달린 노트가 0개인 경우: 해당 태그는 목록에 표시되지 않음 (집계에서 자동 제외)
- 태그 없는 노트(tags: []): 필터 활성화 시 항상 숨김
- 노트 저장/삭제 후 태그 목록: 실시간 재집계

### Out of Scope (이번 구현 제외)

- 다중 태그 동시 선택
- AND/OR 조건 필터
- 텍스트 검색과 태그 필터 조합
- 태그 정렬 옵션 (가나다순, 사용빈도순 등)
- 태그 클라우드 (사용 빈도별 크기 차등)
- 흐리게(dim) 처리 방식

### 용어 정의

| 용어                         | 정의                                                        |
| ---------------------------- | ----------------------------------------------------------- |
| **태그 목록**                | 사이드바 상단에 노출되는 현재 사용 중인 태그들의 집합       |
| **선택된 태그(selectedTag)** | 현재 필터로 활성화된 단일 태그. null이면 전체 표시          |
| **하이라이트**               | 선택된 태그와 일치하는 카드/뱃지를 시각적으로 강조하는 상태 |
| **필터링**                   | selectedTag 기준으로 노트 목록을 숨김 처리하는 동작         |
| **태그 없음**                | 모든 노트의 tags[]가 비어있어 집계 결과가 0개인 상태        |
