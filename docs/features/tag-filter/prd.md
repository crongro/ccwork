# Tag Filter PRD

## 개요

사이드바 상단에 현재 노트들에서 사용 중인 태그 목록을 노출하고, 태그 클릭 시 해당 태그가 달린 노트만 필터링해 표시한다. 선택된 태그와 일치하는 카드 및 카드 내 뱃지를 하이라이트해 사용자가 필터 상태를 명확히 인지할 수 있게 한다.

## 사용자 스토리

### US-1. 태그로 노트 필터링

> 노트 앱 사용자로서, 사이드바 상단에서 태그를 클릭해 해당 태그가 달린 노트만 볼 수 있다. 그래야 관련 노트를 빠르게 찾을 수 있다.

**수용 기준**

- 사이드바 상단에 현재 사용 중인 태그 목록이 칩 형태로 표시된다.
- 태그 클릭 시 해당 태그가 달린 노트만 목록에 표시된다.
- 태그가 없는 노트는 필터 활성화 시 숨겨진다.
- 재클릭 시 필터가 해제되고 전체 노트가 다시 표시된다.

### US-2. 하이라이트로 필터 상태 인지

> 노트 앱 사용자로서, 태그 선택 시 관련 카드와 카드 내 태그 뱃지가 강조되어 어떤 노트가 선택된 태그를 가지는지 한눈에 알 수 있다.

**수용 기준**

- 선택된 태그가 달린 카드는 시각적으로 강조된다.
- 카드 내에서 선택된 태그 뱃지만 하이라이트된다.

### US-3. 태그 없는 상태 처리

> 노트 앱 사용자로서, 태그가 없을 때 빈 영역 대신 안내 문구를 볼 수 있다.

**수용 기준**

- 모든 노트의 tags[]가 비어있으면 태그 영역에 "태그 없음"이 표시된다.

## 기술 결정 (ADR)

### ADR-1. 태그 필터 상태 관리 — App.tsx + useTagFilter 커스텀 훅

**Context**
태그 필터는 서버 상태(notes[])가 아닌 UI 상태다. CLAUDE.md의 3계층 분리 원칙(서버 상태 = NotesContext, UI 상태 = App.tsx, 폼 상태 = NoteEditor)을 유지하면서 집계/필터 로직을 컴포넌트 밖으로 분리해야 한다.

**Decision**
`selectedTag: string | null`을 App.tsx에 추가하고, 집계와 필터 로직은 `useTagFilter(notes, selectedTag)` 커스텀 훅으로 분리한다. 훅은 `{ allTags: string[], filteredNotes: Note[] }`를 반환한다.

**Alternatives**

- A안(prop drilling): 필터/집계 로직이 컴포넌트 안에 섞여 단위 테스트가 어렵고, props depth 증가. 거부.
- B안(NotesContext 확장): UI 상태를 서버 상태 Context에 혼합해 CLAUDE.md 3계층 분리 원칙 위반. 거부.

**Consequences**

- 👍 기존 3계층 분리 원칙 유지. 훅을 `renderHook`으로 독립 테스트 가능. `string | null` → `string[]` 확장 시 훅 내부만 수정.
- 👎 TagPanel, NoteList, NoteItem에 selectedTag 관련 props가 추가되어 인터페이스가 소폭 늘어남.

### ADR-2. 태그 목록 구성 — 현재 노트에서 실시간 집계

**Context**
표시할 태그 목록의 출처를 결정해야 한다. 별도 태그 저장소는 현재 구조에 없다.

**Decision**
`useTagFilter` 훅 내부에서 `notes`를 순회해 `tags[]`를 flat하게 펼치고 중복을 제거해 `allTags`를 도출한다. API 변경 없음.

**Alternatives**

- 별도 `/tags` API 엔드포인트 추가: 오버엔지니어링. 현재 노트 수 규모에서 클라이언트 집계로 충분. 거부.

**Consequences**

- 👍 API 변경 없이 구현 가능. 노트 추가/삭제 시 태그 목록이 자동 갱신.
- 👎 노트가 매우 많아지면 매 렌더마다 집계 연산 발생 — 현재 규모에서는 무시 가능.

## Out of Scope

- 다중 태그 동시 선택 (AND/OR 조건)
- 텍스트 검색과 태그 필터 조합
- 태그 정렬 옵션 (가나다순, 사용빈도순 등)
- 태그 클라우드 (사용빈도별 크기 차등)
- 흐리게(dim) 처리 방식
- 태그 없는 노트 별도 그룹화
- 태그 색상 커스터마이징

## 용어 정의

| 용어                         | 정의                                                        |
| ---------------------------- | ----------------------------------------------------------- |
| **태그 목록**                | 사이드바 상단에 노출되는 현재 사용 중인 태그들의 집합       |
| **선택된 태그(selectedTag)** | 현재 필터로 활성화된 단일 태그. null이면 전체 표시          |
| **하이라이트**               | 선택된 태그와 일치하는 카드/뱃지를 시각적으로 강조하는 상태 |
| **필터링**                   | selectedTag 기준으로 노트 목록을 숨김 처리하는 동작         |
| **태그 없음**                | 모든 노트의 tags[]가 비어있어 집계 결과가 0개인 상태        |
