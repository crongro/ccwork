# 03 — Spacing Tokens

> 기준 리듬은 **1.4rem (`spacing.4`)**. 정의되지 않은 px 값 사용 금지.

## 주요 값

| 용도                         | 토큰         | 값      |
| ---------------------------- | ------------ | ------- |
| 미세 간격 (label↔input)      | `spacing.1`  | 0.35rem |
| 헤드라인 ↔ 본문              | `spacing.2`  | 0.7rem  |
| 기본 리듬 / 리스트 항목 간격 | `spacing.4`  | 1.4rem  |
| 섹션 블록 간격               | `spacing.10` | 3.5rem  |

## 원칙

- **여백은 구조다**. 의심스러우면 여백을 늘린다.
- **리스트 분리는 간격으로만**. divider 라인 금지.
- **섹션 호흡**은 `spacing.10`으로 확보해 "Atmospheric" 품질 유지.

## 금지

- 🚫 리스트 항목 사이 `<hr>` / `border-bottom` 사용
- 🚫 정의되지 않은 px/rem 값
